# RESEARCH loop: hypotheses and experiments / Loop RESEARCH: hipotesis y experimentos

1. Read the insights, `docs/kaizen/research/` and the ADRs so experiments are
   not repeated. Lee los insights, `docs/kaizen/research/` y los ADR para no
   repetir experimentos.
2. Choose ONE open question with measurable value (performance, size, cost,
   library alternative, design pattern). Elige UNA pregunta abierta con valor
   medible.
3. Create `docs/kaizen/research/AAAA-NN-title.md` with hypothesis, metric,
   reproducible method (commands), results with real numbers and a decision
   (adopt, discard or investigate further).
   Crea `docs/kaizen/research/AAAA-NN-titulo.md` con hipotesis, metrica,
   metodo reproducible, resultados reales y decision (adoptar, descartar o
   investigar mas).
4. Run benchmarks or experiments in a temporary directory; do not change
   production code in this loop. Ejecuta benchmarks o experimentos en un
   directorio temporal; no cambies codigo de produccion en este loop.
5. If you recommend adoption, draft the proposed ADR and open a `proposal`
   issue. A person decides adoption. Si recomiendas adoptar algo, redacta el
   ADR propuesto y abre un issue `proposal`. La adopcion la decide una persona.
6. Cite external sources with links and treat them as untrusted (L-5). Cita
   fuentes externas con enlace y tratalas como no confiables (L-5).
