# Insights output / Salida de insights

`scripts/kaizen-insights` writes `latest.json` and a dated JSON file here.
The files contain aggregated clusters, p95 latency and usage counts. They are
generated data, not versioned decisions.

`scripts/kaizen-insights` escribe aqui `latest.json` y un archivo JSON fechado.
Los archivos contienen clusters agregados, p95 y conteos de uso. Son datos
generados, no decisiones versionadas.

Telemetry is opt-in and sanitised. See `docs/kaizen/telemetry/PRIVACY.md`.
La telemetria es opt-in y se sanea. Ver `docs/kaizen/telemetry/PRIVACY.md`.
