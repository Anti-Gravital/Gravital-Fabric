# Iteration journal / Diario de iteraciones

One file per loop iteration, named `AAAA-MM-DD-<loop>-<hour>.md`, containing
the task, decision, evidence (real commands and results), outcome and one
learning. An entry is required even when there was no work.

Un archivo por iteracion, con nombre `AAAA-MM-DD-<loop>-<hora>.md`, que
contenga tarea, decision, evidencia (comandos y resultados reales), resultado y
un aprendizaje. Se requiere entrada incluso si no hubo trabajo.

Journal entries are the loop's only memory (rule L-2).
Las entradas del diario son la unica memoria del loop (regla L-2).
