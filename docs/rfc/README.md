# RFC process

An RFC precedes a new crate, a contract change, a new engine, a security
change, a performance target, a roadmap change or a CI change. Mandatory
sections: title, motivation, problem, alternatives, design, implementation
plan, risks, impact and rollback. An accepted architectural decision leaves an
ADR.
