# Master document policy

1. The canonical Blueprint is `GRAVITAL-FABRIC-Blueprint-v1.0.md`. It defines
   vision, positioning and scope.
2. `GRAVITAL-FABRIC-Hoja-de-Ruta.md` defines what may be built and when.
3. `GRAVITAL-FABRIC-Arquitectura-Tecnica.md` defines how it is built.
4. If a PDF artifact is exported from this repository in the future and
   differs from the markdown, the markdown governs.
5. Master documents are not renamed, fragmented arbitrarily or moved out of
   `docs/master/`.
6. A change to a master document requires an RFC and is reflected in this
   version record and in the README in the same commit.
7. Integrity hashes, when introduced, are verified in CI.
